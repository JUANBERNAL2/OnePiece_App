
# One Piece App

Una aplicación móvil desarrollada en **React Native** inspirada en el universo de *One Piece*. Este proyecto utiliza **Node.js** para gestionar dependencias y scripts, el empaquetador **Metro** y se ejecuta fácilmente en **Expo Go**. Descubre personajes, datos e historias de la serie mientras practicas desarrollo multiplataforma.

## Características

- Lista y detalles de personajes de One Piece
- Visualización de imágenes y descripciones
- Navegación amigable y diseño inspirado en la serie
- Compatible con Expo Go para pruebas rápidas en dispositivos móviles

## Instalación

> **Requisitos:**  
> - Node.js instalado  
> - npm
> - Expo CLI (`npm install -g expo-cli`)

1. Clona el repositorio:
   ```bash
   git clone https://github.com/tu-usuario/one-piece-app.git
   cd one-piece-app
   ```

2. Instala las dependencias:
   ```bash
   npm i

3. Inicia el servidor de desarrollo:
   ```bash
   npm start


4. Escanea el QR desde la app **Expo Go** en tu dispositivo móvil.

## Uso

- Ejecuta `npm start` abre la app con Expo Go.
- Navega entre los distintos personajes y descubre contenido exclusivo de One Piece.
